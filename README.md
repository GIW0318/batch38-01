# GSB Bugfix Task
## 题面
战争迷雾改格子后，玩家能隔墙看到敌人、已探索区域读档后全黑：视野半径按曼哈顿算，墙体遮挡只查中心点，队伍共享只同步当前位置，已探索格回访不保留，读档不恢复探索，隐身单位仍被点亮，雾的边角出现锯齿，状态返回内部格图。fog_reveal.py 的 FogGrid 负责 reveal(player, x, y, now)、share(team, player)、save() 和 snapshot()。地图 64 乘 64；视野用半径 8 的圆形加射线遮挡，墙格阻挡且自身可见；已探索格永久保留，当前可见与已探索分开；队伍共享只同步已探索，当前位置按各自视野；读档恢复两份位图；隐身单位不点亮；边缘格按覆盖率给 0 到 1；越界坐标、负半径、未知玩家报错；save 返回可序列化快照；snapshot 给可见数、已探索数、共享队伍数。十五条用例全红。

## 运行方式
```bash
python -m pytest tests -q
```
