# GSB Bugfix Task
## 题面
拖尾特效一换新实现就断成一节一节：采样点间距按帧而不是按距离；寿命到了整条消失；宽度曲线只用首尾两点；UV 不随长度滚动；面向相机用固定 up 导致翻转；两段拖尾重叠处深度打架；池子满了直接丢弃新拖尾；暂停时寿命还在走。ribbon_trail.py 的 TrailPool 负责 emit(point, now)、update(now)、build(camera) 和 snapshot()。采样间距按世界距离 0.1 米，插值补点；寿命按秒，过期点从头部淘汰；宽度沿寿命做曲线采样，至少 4 个控制点；UV 的 v 按累计长度除以总长；面片用相机位置和切线叉乘，退化时回退上一帧朝向；同池拖尾按创建时间排序，深度偏移 1e-4；池容量 32，满了按最旧淘汰；暂停时 update 不推进寿命；负寿命、零间距、空点集报错；build 返回顶点数和索引数；snapshot 给活动拖尾、点数、淘汰数。十五条断言全红。

## 运行方式
```bash
python -m pytest tests -q
```
