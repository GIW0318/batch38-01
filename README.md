# GSB Bugfix Task
## 题面
地形改造后要重新铺草，结果草地一块密一块秃：随机数用全局种子导致每块一样；坡度过滤没生效；水面和道路上也长草；密度按数量而不是每平方米；最小间距没有；远处实例不裁；每帧重建全部实例；风速相位写死；ledger 泄露内部结构列表。foliage_scatter.py 的 FoliageScatter 负责 scatter(area, density, seed)、cull(camera) 和 ledger()。area 有宽、高、高度图和掩码；密度是每平方米株数；用 seed 做确定性抖动网格，最小间距 0.5 米；坡度超过 35 度、水面、道路掩码为 0 的位置跳过；每株带随机旋转、缩放和风速相位；cull 按距离分三级，超过 200 米剔除；实例预算 10000；负密度、空掩码、尺寸不匹配报参数错误；scatter 返回实例数和被过滤数；ledger给出各级实例数和种子摘要。十五条检查目前全部失败，别改测试。
